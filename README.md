# AnimeWatch - Website Streaming Anime Indonesia

Website streaming anime yang dioptimalkan untuk perangkat mobile (HP), menggunakan data dari AnimePahe.

## Fitur Utama
- **Tampilan Khusus HP**: Navigasi bawah untuk akses cepat.
- **Bahasa Indonesia**: Antarmuka sepenuhnya dalam Bahasa Indonesia.
- **Streaming Lancar**: Menggunakan pemutar video yang responsif.
- **Pencarian Cepat**: Temukan anime favorit Anda dengan mudah.

## Cara Mengonlinekan (Mendapatkan Link Publik)
Agar website ini bisa dibuka oleh siapa saja lewat link (misalnya `nama-web.vercel.app`), ikuti langkah mudah ini:

1. Buat akun gratis di [Vercel](https://vercel.com).
2. Hubungkan akun GitHub Anda.
3. Pilih proyek ini dan klik **Deploy**.

## Cara Menjalankan Secara Lokal
```bash
npm install
npm run dev
```

## Teknologi
- Next.js 15
- Tailwind CSS
- Consumet Extensions (AnimePahe)
